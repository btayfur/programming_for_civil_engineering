# Computer Programming for Civil Engineering

A comprehensive, 14-week university course that introduces **second-year Civil Engineering students** to computer programming using **Python**. The course balances theory and practice, with all examples and exercises grounded in real civil engineering problems — from calculating distributed loads to structural analysis with OpenSeesPy.

> **Author:** Dr. Bilal Tayfur  
> **Term:** Spring Term  
> **Weekly Hours:** 2 hours (theory + practice)

## 📅 Weekly Curriculum

| Week | Topic | Key Concepts |
|:----:|-------|-------------|
| **1** | Introduction to Programming & Python | What is programming, why Python, installation & first run |
| **2** | Algorithms, Variables & Data Types | Algorithm schematics, variables, type casting, intro to functions |
| **3** | Operators & Expressions | Arithmetic, assignment, comparison, logical, and bitwise operators |
| **4** | Control Flow — Conditionals | `if-else` statements, `match-case` (structural pattern matching) |
| **5** | Control Flow — Loops | `for` loops, `while` loops, numerical integration (Riemann sums) |
| **6** | Data Structures & Libraries | Lists, dictionaries, tuples, intro to `pip` and package management |
| **7** | Math & Arrays | `math` module, NumPy arrays (1D & multi-dimensional), Pandas DataFrames |
| **8** | Strings & Text Processing | String operations, methods, regular expressions |
| **9** | Functions & Error Handling | Function structure, scope, special functions, `try-except` patterns |
| **10** | File Handling & CSV | Reading/writing/appending/modifying CSV files, data parsing |
| **11** | Data Visualization | Matplotlib & Seaborn: histograms, scatter plots, box plots, dashboards |
| **12** | Applied Example — Data Import | Importing and visualizing real-world data from online sources (e.g., USGS) |
| **13** | Applied Example — Structural Analysis | Truss & beam problems using **OpenSeesPy** |
| **14** | Advanced Topics | Object-Oriented Programming (inheritance, polymorphism, encapsulation, abstraction) |
